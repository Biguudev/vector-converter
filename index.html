2. Export

XML export now uses a contour-based structure modeled on the user-provided importable example. It is still experimental: coordinate centering, holes, and shape geometry may need adjustment. Test in Alight Motion before relying on it. SVG remains the reliable output.

What this prototype can and cannot do

  • Can trace multiple colored regions and keep each SVG path separately editable in vector software.
  • Can export a scene XML draft with one shape layer per traced path.
  • Does not understand semantic parts such as “hair”, “face”, or “shirt”; separate paths are color/region segments, not AI-recognized body parts.
  • Does not remove a photo background with AI segmentation yet. Best results come from transparent PNGs, cartoons, logos, and flat illustrations.
  • All image processing runs locally after the tracing library loads. The library is fetched from a public CDN; the image itself is not uploaded.
